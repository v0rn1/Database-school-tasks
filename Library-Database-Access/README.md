# Library Database

A Microsoft Access database project created as part of my school programming education.

## Project Description

This project involves creating and managing a library database using Microsoft Access.

The database stores information about library readers and book loans. It also includes multiple queries (kwerendy) used to search, filter and organize records.

## Database Tables

- **Czytelnik (Reader)** – stores information about library readers.
- **Wypożyczenia (Loans)** – stores information about book loans and their dates.

## Queries

The project includes queries for:

- Finding readers by surname.
- Filtering readers by first letter of their surname.
- Searching for readers using specific criteria.
- Finding books that have not been returned.
- Filtering loans by date.
- Excluding readers from selected cities.
- Filtering readers by surname range.

## Technologies

- Microsoft Access
- SQL
- Relational Database Management

## Purpose

The purpose of this project was to practice database management, creating queries, filtering records and working with relationships between tables.
