# Medical Clinic Database

A relational database project created using Microsoft Access as part of my school programming education.

## Project Description

The project focuses on creating and managing a database for a medical clinic (Przychodnia).

The database consists of three main tables:

- **Pacjent (Patient)** – stores patient information.
- **Usluga (Service)** – stores medical services and their prices.
- **Wizyta (Visit)** – stores information about patient visits, selected services and quantities.

## Database Queries

The project includes several queries (kwerendy):

- Filtering patients by surname and first name.
- Finding medical services with a price greater than 20.
- Finding patients younger than 40.
- Calculating the net and gross value of services.
- Summarizing the total gross value of services for each patient.

## Calculations

- Net value = Service price × Quantity
- Gross value = Net value × 1.23

## Technologies

- Microsoft Access
- SQL
- Relational Database Design

## Purpose

The purpose of this assignment was to learn how to create relational databases, establish relationships between tables, write queries, filter records and perform calculations using Microsoft Access.
